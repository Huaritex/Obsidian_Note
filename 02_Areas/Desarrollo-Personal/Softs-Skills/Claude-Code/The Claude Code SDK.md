>[!note] El SDK de Claude Code te permite ejecutar Claude Code mediante programación desde tus propias aplicaciones y scripts. Está disponible para TypeScript, Python y a través de la línea de comandos, ofreciéndote la misma funcionalidad de Claude Code que utilizas en la terminal, pero integrada en flujos de trabajo más amplios.

![[Pasted image 20260305130705.png]]

- El SDK ejecuta el mismo código Claude con el que ya estás familiarizado. Tiene acceso a las mismas herramientas y las utilizará para completar cualquier tarea que le asignes. Esto lo hace especialmente potente para escenarios de automatización e integración.

## Caracteristicas Principales

- Ejecuta Claude Code mediante programación
- Misma funcionalidad que la version de terminal
- Hereda la configuracion de las instancias de Claude Code en el mismo directorio
- Permisos de solo lectura por defecto
- Muy util como parte de flujos de trabajo o herramientas mas amplias
